# Training_Planner
Автор: Зарифуллин Тимур
Описание:
Это программа, которая помогает планировать тренировки. Ты можешь добавлять тренировки, указывать дату, тип и сколько минут ты тренировался. Также можно искать тренировки по дате или типу.
Как пользоваться:
1. Запусти программу.
2. Введи дату (например, 2023-08-15), тип тренировки (например, бег) и длительность (в минутах).
3. Нажми кнопку «Добавить тренировку», чтобы сохранить.
4. Чтобы найти определённую тренировку, введи тип или дату в фильтры и нажми «Применить фильтр».
5. Чтобы посмотреть все тренировки — нажми «Сбросить фильтр».
Все данные сохраняются в файле trainings.json, чтобы не потерять их при закрытии программы.
